# 読解練習

短い文章を読んで、「だれが・だれに・何を・何のために」を**言葉で答える**練習アプリ。

- 仕様は [SPEC.md](SPEC.md) に全部書いてあります。
- 問題は `data/questions.json` の1ファイルだけ。**問題を足すときは、このファイルに書き足すだけ**です。

---

## 1. 動かす

素の HTML / CSS / JavaScript だけで出来ています。ビルドは要りません。

ただし `data/questions.json` を `fetch` で読むので、**ファイルを直接ダブルクリックしても開けません**。
手元で見るときは、このフォルダで次を実行してから `http://localhost:5195` を開きます。

```bash
python3 -m http.server 5195
```

公開は GitHub Pages（`https://kantanapp.github.io/dokkai-renshu/`）。
パスはすべて相対パスなので、サブパスのまま動きます。

### ファイル

```
index.html             画面の骨組み（4画面ぶん）
css/style.css          見た目。色と大きさは :root の変数にまとめてある
js/app.js              動き。ふりがな・黄色い印・記録の保存・画面の行き来
data/questions.json    問題（ここだけ足していく）
manifest.webmanifest   ホーム画面に追加するときの設定
sw.js                  オフライン用（ネットワーク優先・失敗したらキャッシュ）
icons/                 アイコン 180 / 192 / 512px
tools/check.py         問題データの点検
design-reference/      チャットで作った画面案の元データ（参考用・アプリは使わない）
SPEC.md                仕様書
```

## 2. 問題を足す

`data/questions.json` の `levels` → 該当レベルの `sets` に、セットを1つ足します。
**1セット＝文章1つ＋設問5つ**です。

```json
{
  "id": "3-1",
  "passage": "「これ、落としたよ。」{由香|ゆか}が差し出したのは、…",
  "questions": [
    {
      "kind": "指すもの",
      "q": "「これ」とは何ですか。",
      "focus": "「これ、落としたよ。」",
      "answer": "夏美の定期入れ",
      "evidence": ["差し出したのは、夏美の定期入れ"],
      "steps": ["どこを見るか。", "だからこう読める。"],
      "open": false
    }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `id` | `レベル番号-セット番号`。セットの通し番号は、この並び順で決まる |
| `passage` | 文章。改行は `\n`。ふりがなは `{漢字\|よみ}` |
| `kind` | 問いの種類。今あるのは「指すもの」「だれが、だれに」「だれのせりふ」「理由」「気持ち」「何のために」「出来事」 |
| `q` | 問いの文（ふりがな記法が使える） |
| `focus` | 問いが指している文章中の箇所。**問題画面で黄色**になる。無くてもよい |
| `answer` | 答えの例（ふりがな記法が使える） |
| `evidence` | 根拠の箇所。**解説画面で黄色**になる。複数可 |
| `steps` | 解説。番号つきで順に出る（ふりがな記法が使える） |
| `open` | `true` なら「文章に答えが直接書かれていない問い」。解説に一言が添えられる |

- `sets` が空のレベルは、ホームで「準備中」と出て押せません。足せば自動で押せるようになります。
- `focus` と `evidence` は、**ふりがなを取りのぞいた文章**の中の文字列を書きます。
  （`{夏美|なつみ}の定期入れ` → `夏美の定期入れ` と書く）
- 同じ文字列が文章に2回出るときは、**最初の1つ**に印が付きます。

### 書くときのルール

SPEC.md「9. 問題を作るときのルール」が正本です。かいつまむと:

- 文章は書き下ろし。既存の作品は使わない（著作権）。
- 1つの文章に5問。**言葉で答える問い**にする。選択肢は作らない。
- 答えが文章に直接書かれていない問い（気持ち・目的）は `open: true`。
- 全問に `steps` と `evidence` を付ける。解説は「どこを見るか」→「だからこう読める」の順。
- ふりがなは ①人名（その文章で最初に出るところ）②小学校で習わない漢字 ③読み方が分かれる語。

## 3. 足したら必ず点検する

```bash
python3 -m venv .venv
.venv/bin/pip install kanji-lists
.venv/bin/python tools/check.py
```

点検するのは、字数・設問数・`focus` と `evidence` が文章に実在するか・ふりがなの付けもれ・ふりがな記法のくずれ。
**「問題は見つかりませんでした。」が出るまで直してください。**

`.venv` は一度作れば、次からは最後の1行だけで動きます。

---

## 4. 記録について

- 書いた答え・丸つけ・やり直し中の問いは、**その端末のブラウザの中だけ**（localStorage）に残ります。
- サーバーには何も送りません。ログインもありません。
- そのため **iPhone と iPad で記録は別**になります。Safari の履歴・データを消すと、記録も消えます。
- ホームのいちばん下の「記録を消す」で、手で消せます。

---

## 5. ホーム画面に追加する（PWA）

iPhone / iPad の Safari で公開URLを開き、共有ボタン →「ホーム画面に追加」。
アイコンとして「読」が並び、アドレスバーの無い状態で開きます。電波が無くても開いて解けます。

取り方は **ネットワーク優先、失敗したらキャッシュ**（`sw.js`）。
つながっているときは必ず新しいものを取りにいくので、**問題を足したら次に開いたときに出ます**。

> アイコンや `sw.js` を差し替えたときは、`sw.js` の `CACHE` の名前（`dokkai-renshu-v4`）を
> `-v2` のように変えてください。古いキャッシュが捨てられます。

## 7. GA4（アクセス解析）

`js/ga.js` の先頭にある `GA_ID` に測定ID（`G-` から始まる）を入れると動きます。
**空のままなら GA4 は読み込まれず、何も送りません**（アプリは普通に動きます）。

```js
var GA_ID = 'G-66R7MWB5JF';
```

### 送るイベント

| イベント名 | 送るとき | パラメータ |
|---|---|---|
| `screen` | 画面が切り替わったとき | `view_name`（home / question / check / result） |
| `set_start` | セットを開いたとき | `set_id`, `level`, `mode`（normal / retry） |
| `answered` | 「答えた」を押したとき | `set_id`, `q_no` |
| `answer_empty` | 空のまま「答えた」を押したとき | `set_id`, `q_no` |
| `read_kaisetsu` | 「わからなければ解説を読む」 | `set_id`, `q_no` |
| `self_mark` | ○△×を押したとき | `set_id`, `q_no`, `mark`（o / t / x） |
| `set_complete` | セットが終わったとき | `set_id`, `level`, `kind`, `o_count`, `t_count`, `x_count` |
| `retry_start` | やり直しを始めたとき | `set_id`, `retry_count` |

### 送らないもの

**書いた答えの中身は絶対に送りません。** 送るのは上の表のものだけです。
子どもが使うアプリなので、広告まわりの機能（Google シグナル・広告のパーソナライズ）も切ってあります。

### GA4 側でやること

パラメータを管理画面で見るには、**カスタムディメンション**として登録が必要です
（管理 → データの表示 → カスタム定義 → カスタムディメンションを作成、範囲は「イベント」）。

`view_name` / `set_id` / `level` / `q_no` / `mark`

登録しなくてもイベント数は「レポート → エンゲージメント → イベント」で見られます。

### 注意

- 電波が無いときの操作は送られません（GA4 はオフラインで貯めません）。
- 測定IDを変えたら、`sw.js` の `CACHE` 名も上げてください。
